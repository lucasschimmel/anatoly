# Anatoly terminal identity

- Name: ANATOLY, dense six-row beveled wordmark with recessed outlines.
- Header hierarchy: small research masthead and version, wordmark, compact subtitle.
- Palette: ice-to-cyan-to-electric-blue faces, dark blue bevels, graphite separator.
- Wordmark fits a standard 80-column terminal; no stretched pixel glyphs.
- Results: red potentially affected/error, amber inconclusive, cyan floor observed.
- Do not present a green safe/secure verdict based on HTTP observations.
- Human output: evidence, per-CVE result, limitations, then next action.
- JSON: no banner or ANSI, stable snake_case values; unknown remains explicit.
- Support redirected stdout, NO_COLOR, and --no-banner.
- Scan results: 78-column cards with blue rails and an immediately visible verdict.
- Numbered cyan sections: runtime, CVEs, configuration, next action, assessment limits.
- Use readable status text, wrap long URLs and prose, group undisclosed directives.
- Keep per-CVE uncertainty and all assessment limitations visible; JSON retains full evidence.
- Finish a scan with an aggregate summary: exclusive outcome counts, overlapping evidence counters,
  incomplete coverage, and explicitly unattested certified/secure counts.
- Version evidence levels describe observation quality, never a numerical security score.
- Expose declared/corroborated/contradictory/unknown levels and proof sources for each candidate.
- Separate cookie/CMS/Composer/error-behavior hypotheses into an amber block.
