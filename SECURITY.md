# Security policy

Only the latest released version is supported. Advisory floors are a dated static
snapshot; verify vendor guidance independently and do not interpret exit 0 as a
security attestation.

For vulnerabilities in Anatoly, use GitHub's **Report a vulnerability** feature on
this repository when available. Do not publish credentials, session values, private
targets or an actionable vulnerability in a public issue. Public issues are suitable
for sanitized, non-sensitive bugs and questions.

Reports should include the affected version, expected behavior, impact, a local
reproducer and proposed mitigation if known. There is no guaranteed response time.

This project does not own PHP2Shell or PHP. Report PHP vulnerabilities to PHP's
maintainers. Use Anatoly only on systems you are authorized to assess.
